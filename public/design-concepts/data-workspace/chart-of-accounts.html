Reusable pattern reference

Every state below is a documented, reusable primitive. Any Data Workspace surface — Trial Balance, Vendors, Members, Employees, Fixed Assets, Inventory, Budgeting, Journal Entries — composes from the same set. This section is a reference sheet, not a live workflow.

Validation state
Warning Blocked

Coexists with lifecycle: "Active · Warning" (allowed) vs "Active · Blocked" (cannot post). Combined with a left-edge row stripe.
