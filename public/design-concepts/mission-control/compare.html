Mission Control · executive visual refactor

Three variants, same information architecture.

The current Mission Control layout is approved. The current appearance is not. Below are three progressively more ambitious executions of the Executive Interface Standards — same page anatomy, same feed, same rail, same content. What changes is the visual language: typography, whitespace, chrome, and colour restraint.

Variant A · Conservative
Refines the existing design while minimising visual change.
The card structure, sidebar shape, briefing strip, and rail widgets are retained — with the changes required to pass the Standards's most basic tests. Recognisable as an evolution of the current mockup.
Key moves. Emoji icons replaced with a monochrome SVG family. "Mission Control" heading replaced with a human greeting. Card borders softened. Coloured briefing numbers desaturated. Filters and secondary buttons quieter. Same shape, less noise.

Variant B · Executive
Applies the Executive Interface Standards fully while preserving the layout.
Cards give way to architecture. Typography becomes the primary hierarchy mechanism. The page begins with the day rather than with software. Feed items are separated by whitespace and hairlines, not boxes. The rail reads as an executive briefing notebook rather than three widgets. Superseded by Variant D — this reading of the standards proved to sacrifice affordance and scanning speed for editorial restraint.
Key moves. Human briefing replaces the KPI strip. Feed items lose card fills; separation is rhythm. Data cells are typographic — no filled panels. Secondary actions are quiet text links; one primary action per item. Sidebar and top bar drop to near-invisible framing.
Open Variant B
Variant C · Aspirational
Pushes the editorial language as far as possible without changing the information architecture.
A serif display face is introduced for the greeting, state, feed headlines, and rail headings — treating Mission Control as an editorial briefing rather than a screen. Vertical rhythm expanded; cents desaturated; secondary actions become underlined text. Rejected — proved that pushing editorial restraint further only worsens the scanability problem.
Key moves. Display serif for greeting, state, item titles, rail headings. Warmer canvas (ivory). Larger gutters. Cents in a lighter weight, one size down. Rail headings become italic captions with hairlines beneath.
Open Variant C
Variant D · Professional Instrument (recommended)
Recovers the original's clarity, adds craftsmanship, drops the editorial pretence.
Clarity beats minimalism. This variant reads the standards as Bloomberg / Leica / Porsche cockpit — not Apple Settings. Three-plane material system (shell / canvas / workspace) creates visible depth without floating Material cards. The original's KPI-strip briefing is restored as an instrument-panel readout. Feed items are bounded workspaces with left-edge status stripes, disciplined data readouts, primary + secondary + tertiary action tiers, and traceable IDs. The rail is three distinct sections with visible chrome and aligned numerals. Every control has an unmistakable affordance.
Key moves. Warmer canvas + warmer shell + workspace lift (three visible planes). 5-cell instrument briefing with status swatches. Feed items regain card boundaries + left status stripe + ID tag + policy flag. Data readouts return as inset panels with column dividers. Recommendation set in a green-tinted attention band. One filled primary + two bordered secondary + one tertiary text button per item. Top bar gains help + notification-count badge. Sidebar adds a persistent user block. Two full items visible without scrolling at 1440.
Open Variant D
Hard constraint reminder · none of these variants changes the information architecture, the work-intake concept, the executive rail, the page anatomy, or the workflow. Every difference is visual only.
